A program that writes one line about office life to /output/entry.txt.

Entry (117 characters):

> The office printer only jams when the document is urgent, which is why I now print everything at 4:59 PM on a Friday.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed joke to `/output/entry.txt`. Before writing, it validates the text: it must not be blank, must not be digits only, must contain at least one letter, must fit within 199 characters, and must be valid UTF-8. Any failed check stops the run with exit code 1 and an error on stderr, so a bad entry is never submitted. A further check rejects text made up entirely of punctuation, so a string of symbols alone is not accepted as an entry. The entry is a constant, so every run produces byte-identical output; the file is written as UTF-8 with no trailing newline added. Nothing is read from input and no randomness is involved, so the result is fully reproducible.
